# repo-fs-gemini

Monorepo with `client` and `server` workspaces.

## Quick start

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

## Scripts
- `npm run dev` - Run both client and server dev servers.
- `npm run dev:client` - Run the client dev server.
- `npm run dev:server` - Run the server dev server.
- `npm run build` - Build both client and server.
- `npm run build:client` - Build the client.
- `npm run build:server` - Build the server.
